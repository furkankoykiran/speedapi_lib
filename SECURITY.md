# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 2.x     | ✅ Active support  |
| < 2.0   | ❌ End of life     |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please send an email to:
**furkankoykiran@gmail.com**

Include as much of the following information as possible:

- Type of vulnerability (e.g. authentication bypass, HMAC forgery)
- Full paths of affected source files
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the vulnerability

You should receive a response within **48 hours**. If you do not, please follow
up via email to ensure we received your report. We will keep you informed of the
progress toward a fix and may ask for additional information.

## Responsible Disclosure

After a fix has been released, we will:

1. Publish a security advisory on GitHub
2. Add a `CHANGELOG.md` entry under the new patch release
3. Credit the reporter (unless they prefer to remain anonymous)

We kindly ask that you:

- Give us reasonable time to investigate and patch before public disclosure
- Avoid accessing or modifying data that does not belong to you
- Not perform denial-of-service attacks

Thank you for helping keep `speedapi-python` safe for everyone.
